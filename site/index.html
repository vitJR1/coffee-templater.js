What it is forДля чего это

Backends generate documents all the time: invoices, contracts, acts, reports, exports. Quick startБыстрый старт

      

        

          
Render a templateЗаполнить шаблон


import { readFileSync, writeFileSync } from 'node:fs'
import { createTemplater } from 'coffee-templater'

const templater = createTemplater()
const template = templater.compile(readFileSync('invoice.docx'))

writeFileSync('invoice-42.docx', template.render({
  number: 42,
  client: { name: 'Ivan Petrov' },
  items: [{ name: 'Coffee', qty: 2, price: 10.5 }],
  paid: false,
}))

One engine, many languagesОдно ядро — много языков

      

        All document work happens in coffee-templater-engine — a Rust core compiled to WebAssembly and bundled inside the npm package. The same engine is meant to power Go and Python libraries, so a template renders byte-for-byte the same everywhere.
        Вся работа с документами выполняется в coffee-templater-engine — ядре на Rust, скомпилированном в WebAssembly и встроенном в npm-пакет. На этом же ядре будут работать библиотеки для Go и Python, поэтому шаблон везде даёт побайтно одинаковый результат.
